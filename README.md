## 👋 About Me

I'm a self-taught cybersecurity learner with **3+ years** of hands-on practice across multiple security domains. My focus isn't on memorizing tool commands — it's on understanding *why* an attack works, *how* a system fails, and *how* to defend it.

All testing and experimentation shown here is performed in **isolated, local lab environments** (VMs, intentionally vulnerable applications, and CTF platforms) — never against systems I don't own or have explicit permission to test.

- 🔭 Currently deepening my skills in network security, web application security, and exploitation fundamentals
- 🌱 Learning towards: malware analysis, reverse engineering, wireless/RF security, and applied AI security
- 🤝 Open to CTFs, security research collaboration, and knowledge-sharing
- ⚡ Fun fact: I'd rather understand *one* vulnerability class deeply than memorize a hundred tool flags
